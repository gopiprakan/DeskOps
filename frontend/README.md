# Frontend

The Phase 1 user interface will be implemented here using React 18, TypeScript and Vite.

Required frontend standards:
- TanStack Query for server state.
- React Hook Form and Zod for forms and validation.
- Tailwind CSS for styling.
- Playwright for end-to-end journeys.

Planned first user journeys:
1. Resident signs in and creates a maintenance ticket.
2. Resident views their own ticket and public updates.
3. Staff views tickets allowed for their organisation.
4. Technician updates an assigned ticket through permitted states.

Do not assume these pages are implemented until the application and tests exist.
